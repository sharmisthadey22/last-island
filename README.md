# 🏝️ Last Island - Multiplayer Game

🚀 *Live Demo (Play Here):* [https://last-island-61g8.onrender.com](https://last-island-61g8.onrender.com)

A real-time multiplayer web game built with Node.js and Socket.io, deployed live on Render.

## 🛠️ Technical Expertise & Tech Stack

* *Frontend:* HTML5, CSS3, JavaScript (Canvas/DOM)
* *Backend:* Node.js, Express
* *Real-time Communication:* Socket.io (for multiplayer rooms and real-time synchronization)
* *Version Control:* Git & GitHub (sharmisthadey22/last-island)
* *Hosting & Deployment:* Render (Web Service)

## 🎮 Features
* Real-time multiplayer synchronization using WebSockets.
* Room creation and player join system.
* Dynamic safe zone mechanics and win/loss notifications
